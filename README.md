Moderan, minimalistički website za organizaciju koja se bavi održivim razvojem naselja Vrbovsko. Sajt promovišu potencijal naselja kroz saradnju sa institucijama i aktivno učešće zajednice.

## 🚀 Quick Start

### Preduslovi

- [Node.js](https://nodejs.org/) (v18 ili novija verzija)
- [Git](https://git-scm.com/)

### Instalacija

```bash
# Klonirajte repozitorijum
git clone https://github.com/YOUR_USERNAME/VRBOVSKO.git

# Uđite u direktorijum
cd VRBOVSKO

# Instalirajte dependencies
npm install

# Pokrenite development server
npm run dev
```

Server će biti pokrenut na `http://localhost:3000`

## 📋 Dostupne Komande

```bash
# Pokreće development server sa hot reload
npm run dev

# Build-uje projekat za produkciju
npm run build

# Preview produkcione verzije
npm run preview
```

## 🚀 Deployment

### GitHub Pages

Projekat je konfigurisan za automatski deployment na GitHub Pages. Samo push-ujte promene na `main` granu:

```bash
git add .
git commit -m "Vaša poruka"
git push origin main
```

GitHub Actions će automatski build-ovati i deploy-ovati sajt.

### Manuelni Deployment

```bash
# Build projekat
npm run build

# Deploy dist/ folder na vaš hosting
```
