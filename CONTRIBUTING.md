# Kako Doprineti Projektu

Hvala što želite da doprinesete razvoju Vrbovsko sajta!

## Proces Doprinosa

1. **Fork** repozitorijuma
2. **Klonirajte** vaš fork:
   ```bash
   git clone https://github.com/your-username/VRBOVSKO.git
   cd VRBOVSKO
   ```

3. **Instalirajte** dependencies:
   ```bash
   npm install
   ```

4. **Kreirajte** novu granu za vašu feature:
   ```bash
   git checkout -b feature/nova-funkcionalnost
   ```

5. **Napravite** promene i testirajte lokalno:
   ```bash
   npm run dev
   ```

6. **Commit** vaše promene:
   ```bash
   git add .
   git commit -m "Dodato: opis promene"
   ```

7. **Push** na vaš fork:
   ```bash
   git push origin feature/nova-funkcionalnost
   ```

8. **Kreirajte** Pull Request

## Stilski Vodič

- Koristite semantički HTML
- Pratite postojeću strukturu CSS-a
- Pišite jasne commit poruke
- Testirajte na mobilnim uređajima

## Code Style

- **HTML**: Uvlačenje sa 2 space-a
- **CSS**: Uvlačenje sa 2 space-a, koristite CSS varijable
- **JavaScript**: ES6+ sintaksa, jasna imena funkcija

## Reporting Issues

Ako pronađete bug ili imate predlog za novu funkcionalnost, molimo vas:

1. Proverite da već ne postoji issue
2. Kreirajte novi issue sa detaljnim opisom
3. Dodajte screenshot-ove ako je moguće

Hvala vam na doprinosu! 🌲
